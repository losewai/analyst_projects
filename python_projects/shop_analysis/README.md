### Анализ работы магазина

В данном проекте проведен анализ деятельности продуктового ритейла. Основное внимание уделено изучению потребительской аудитории (распределение по возрасту, образовательному цензу, типу семьи), 
оценке финансовой эффективности предприятия в разрезе товарных категорий и каналов продаж (стационарная точка / интернет-площадка), а также оценке откликов на проведенные рекламные активности.

Обработка информации и статистические вычисления реализованы посредством языка Python с привлечением специализированных библиотек: pandas, numpy, scipy, scikit_posthocs, а также средств визуализации seaborn и matplotlib.

Подготовительный этап (очистка данных) включал в себя:

1. Приведение типов данных в соответствие с их содержанием.
2. Анализ полноты данных (поиск пропусков).
3. Поиск и устранение дубликатов и некорректных записей.
4. Генерацию дополнительных признаков (например, для расчета накопительных итогов).  
5. Выявление и обработку статистических выбросов.

Методы анализа:
1. Расчет базовых статистических показателей.
2. Визуализация данных с помощью столбчатых и круговых диаграмм, а также нормированных гистограмм на основе сводных таблиц.
3. Выявление взаимосвязей между признаками (корреляционный анализ по Спирмену) с построением тепловой карты (heatmap).
4. Сравнение нескольких независимых групп с использованием непараметрического критерия Краскела-Уоллиса и последующего post-hoc анализа (критерий Данна), сопровождаемое визуализацией (barplot).
5. Сопоставление двух выборок при помощи U-критерия Манна-Уитни.

Файлы:
1. shop_data.csv — исходный набор данных, включающий информацию о социально-демографическом профиле покупателей, их тратах в офлайн и онлайн-сегментах, а также данные об участии в маркетинговых кампаниях.
2. dictionary.png — изображение-описание, содержащее расшифровку наименований столбцов датасета.
3. shop_analysis.ipynb — Jupyter Notebook с полным кодом вычислений на Python, подробными комментариями и итоговыми выводами по каждому этапу исследования.

Данные взяты из открытого датасета на [Kaggle](https://www.kaggle.com/datasets/jackdaoud/marketing-data)
